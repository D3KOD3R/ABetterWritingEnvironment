# Terminology

- `Project`: the canonical manuscript container for chapters, scenes, and review records.
- `ManuscriptBlock`: an addressable narration or dialogue paragraph.
- `ManuscriptAnchor`: a durable span reference into manuscript content.
- `IssueRecord`: a typed manuscript diagnostic linked to an anchor.
- `EventTag`: a tagged story event linked to an anchor.
- `WorldTemplate`: a structured blueprint for a world entity type.
- `WorldEntity`: an instantiated entity created from a template.
- `TimelineSpine`: a horizontal worldbuilding lane.
- `TimelineNode`: an event on a spine.
- `TimelineEdge`: an explicit relationship between timeline nodes.
- `EntityIntroduction`: the first canonical manuscript and timeline introduction for an entity.
- `World Suggestion Queue`: a reviewable list of proposed templates, entities, or links generated from manuscript evidence before any canonical world mutation.
- `DreamScapeSuggestion`: a reviewable story-fit proposal that links a loose author idea to manuscript and world-spine evidence before creating any canonical scene or timeline data.
